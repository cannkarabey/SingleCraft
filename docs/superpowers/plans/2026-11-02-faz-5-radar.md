## Global Constraints

- Auth via Supabase (`@supabase/ssr`, PKCE): magic link + Google + GitHub OAuth. Protected: `/radar/**`, `/onboarding`, `/studio/**`, `/settings/**`.
- Writes that enforce limits (niche create, usage counters, angles) go through server code with the admin client after an auth check (Faz 1 ruling); reads use the user's session client under RLS.
- No LLM call in HTTP routes: niche embeddings and personal angles run as Inngest functions; routes enqueue and the UI polls.
- Plan limits live in one place: `lib/billing/limits.ts`.
- Free Radar lock is enforced in the API response: rows after the first 3 carry only `{ locked: true, bucket }`.
- Redirect targets after login are same-origin relative paths only.
- All UI text from `messages/{tr,en}.json`.
