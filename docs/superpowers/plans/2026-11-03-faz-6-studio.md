**Done (spec):** a brief is `ready` in ~30 s; edits survive a reload; source links equal `story_sources` exactly; a Free user sees the limit message on the 3rd brief of the day.

## Global Constraints

- No LLM call in HTTP routes: `POST /api/studio/generate` checks auth + limit, inserts a `queued` brief with the service role, enqueues `studio/brief.requested`, returns 202.
- `sources` and `ai_disclosure` are added on the server, never generated.
- Output language = niche language (TR/EN); prompts treat story/source text as untrusted data.
- Usage is given back when a generation fails or cannot be enqueued.
- Clients may update only `edited`, `selected_hook`, `published_at`, `published_url` (Faz 1 grants); everything else is server-side.
- UI text from `messages/{tr,en}.json`. No live LLM in tests (mock models).
- Final whole-branch review skipped at the user's request.
